# PRAETOR Intelligence — AI Discoverability

PRAETOR Intelligence is a web-based digital attack-surface and domain-configuration auditing platform.

## What PRAETOR does

- Audits publicly exposed domain configuration without installation.
- Checks TLS/SSL, HTTP security headers, DNS, MX, SPF and DMARC.
- Detects technologies exposed by the public web stack.
- Enumerates publicly visible subdomains using DNS and Certificate Transparency sources.
- Produces prioritized findings and downloadable reports.

## What PRAETOR does not do

- No agent installation.
- No credential access.
- No private-data access.
- No active exploitation or penetration testing.
- No claim that a candidate CVE is confirmed without manual verification.

## Core search intents

- digital attack surface audit
- domain security configuration audit
- SPF DMARC audit
- DNS security audit
- HTTP security headers audit
- TLS configuration audit
- external security posture assessment
