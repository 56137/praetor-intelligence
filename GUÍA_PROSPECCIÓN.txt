PRAETOR INTELLIGENCE — GUÍA DE PROSPECCIÓN
==========================================

Esta guía no contiene nombres, correos, teléfonos ni historiales de clientes.
Los datos de prospectos deben permanecer en archivos locales excluidos por
.gitignore. No subas esos archivos al repositorio ni los compartas en issues,
logs o capturas.

1. Inicializar un archivo privado de prospectos

   python generate_prospects.py --city "Ensenada, Baja California"

   El comando crea prospectos_ensenada.json con una lista vacía. Si el archivo
   ya existe, no lo sobrescribe.

2. Añadir registros localmente

   Usa la estructura que consume generate_templates.py. Ejemplo ficticio:

   {
     "empresa": "Empresa de ejemplo",
     "tipo": "SaaS B2B",
     "sector": "Tecnología",
     "contacto": "",
     "telefono": "",
     "razon_contacto": "Motivo comercial documentado",
     "caso_uso": "Auditoría externa de exposición",
     "prioridad": "Media"
   }

   No incluyas datos personales que no sean necesarios. Mantén la base privada
   y limita su acceso a quienes participan en el proceso comercial.

3. Generar materiales localmente

   python generate_templates.py

   Los archivos prospectos_*.json, prospectos_*.csv y
   PLANTILLAS_PROSPECCIÓN.txt están excluidos del control de versiones.

4. Credenciales

   No escribas API keys, contraseñas, tokens ni credenciales SMTP en archivos
   Python, JSON, CSV, documentación o comandos versionados. Usa variables de
   entorno y el gestor de secretos del proveedor de despliegue.

5. Antes de contactar

   Verifica que el contacto y la empresa sean correctos, que exista una base
   legítima para el contacto y que el mensaje describa capacidades reales del
   producto. No prometas resultados que no hayan sido comprobados.

Checklist:
[ ] Datos de contacto almacenados solo localmente.
[ ] Archivos locales cubiertos por .gitignore.
[ ] Credenciales gestionadas fuera del repositorio.
[ ] Material comercial revisado antes de enviarse.
